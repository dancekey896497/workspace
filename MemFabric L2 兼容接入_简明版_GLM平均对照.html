01　代码结构

MemFabricL2Adapter 是 LMCache L2 的插件入口。它通过 BMSession 调用 MemFabric SDK 搬运 KV，通过 DirectoryClient 访问共享目录。目录的 HTTP 接口和对象状态分别由 SharedDirectory、PoolDirectory 负责。

源文件类这个文件管什么
memfabric_l2_adapter.pyMemFabricL2Adapter实现官方 L2AdapterInterface，把目录操作交给 RPC 客户端，把 KV 搬运交给 BM。
memfabric_bm.pyBMSession封装 MemFabric SDK 会话与数据搬运，管理内存注册和复制。
memfabric_directory_rpc.pyDirectoryClient服务进程内的 HTTP 客户端，把目录请求发给协调器。
pool_coordination.pySharedDirectory提供目录 HTTP 接口，校验访问方与目录实例，加载 PoolDirectory。
memfabric_directory.pyPoolDirectory保存对象键、槽位、发布状态和读锁，决定何时回收槽位。

跨机共享这次改动新增了目录和 RPC 客户端，并把它们接入已有的适配器、协调器和 BM 会话。查看逐文件改动、提交与原始 Git diff

04　GLM-5.1 端到端性能对照

本轮比较两套双机 DDR 池化方案。MemFabric 兼容 L2 使用 DEVICE_RDMA，Mooncake Store 使用经典 TE 的 ascend 传输。137 和 25 各提供 8 GiB DDR，各运行一套 GLM-5.1。由 137 预填并写池，25 号机发出正式请求。

## 对照候选版的六个行为点

| 检查点 | 合格条件 | 若不同怎么办 |
|---|---|---|
| 写侧快照时点 | 源对象预留有效时，在 `run_in_executor` 提交前完成 `bytes(buf)` | 不能认为实现等价；改正后只补写侧取消/复用测试 |
| 对齐和所有权 | executor worker 自己创建、持有、释放普通对齐 mmap；实际系统调用接收该 view | 若仍直接传 bytes/ACL view，需要修补并重做相应读写验证 |
| 读回 | 只有 `n == expected` 才返回独立 payload；协程恢复后复制到字节视图，再置成功位 | 若短读回写或提前置位，改正后补短读测试 |
| 取消 | 协程取消不会关闭线程仍在使用的 mmap；线程不再接触借用的目标/源 | 若仅验证放弃等待，不扩大为完整关闭结论；必要时补真实任务取消一项 |
| 短写和发布 | 写入不满即失败，不发布正式文件；临时文件打开含 `O_TRUNC` | 只补对应异常用例 |
| 异常传播 | `continue` 在 `finally` 外，不吞异常/取消；buffered 路径保持原语义 | 先修代码，再验证受影响路径 |

1. `STATX_DIOALIGN=0x2000`，`0x17ff & 0x2000 == 0`。该返回值**不包含有效 DIO 对齐字段**，不能把零值解释为“支持但对齐为零”，不能据此证明实际绕过页缓存。

3. 现场通过的是特定版本、配置、参数组合的功能；完整 controller 关闭、原首个 load 挂死的唯一根因、精确重算量不在这份补丁的已验证承诺里。

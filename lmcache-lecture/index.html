LMCache 图解讲义

从「KV Cache 是什么」讲到「CUDA IPC 的 handle 怎么跨进程传」，全程配图。
面向完全没接触过 L1/L2 分层、也没读过 LMCache 源码的读者。

先给你一张全景图 一句话概括本讲义要讲的东西：
vLLM 把 KV Cache 放在 GPU/NPU 显存里（L1）；LMCache 把它搬到 CPU 内存（L1）、本地盘（L2）、远端存储（L3）去，让下一次请求能直接「捡回来」；LMCache-Ascend 是让这套搬运逻辑在昇腾 NPU 上跑起来的适配层。

§0这个工作区里没有什么

重要前提 你给的工作区 vllm_base 里没有 vLLM / LMCache 的源码副本（只有我这次写入的讲义文件）。 所以本讲义中的代码片段来自两个开源仓库的公开代码路径，按「文件路径 + API 名字」组织， 是对真实代码结构的讲解，不是从本地文件里抓的。
另外本次会话的网络只能访问 github.com，raw.githubusercontent.com / docs.lmcache.ai / CDN 都被拒绝解析，所以无法逐行核对最新 main 分支。凡是我标记 版本相关 的地方，请以你本地实际安装版本的代码为准。
